## Reading it

- The cutoff is set where normal transactions end. In this synthetic data that edge is unusually sharp; with real data the trade-off is gradual and the cutoff would be set by agent capacity and rechecked against confirmed disputes.
- Fraud below the cutoff is not caught by this rule. Other signals (no matching transaction, the customer asking for a person) still route cases to an agent.
